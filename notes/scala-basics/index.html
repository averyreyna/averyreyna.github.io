Scala Basics

Working through the Scala tour: values, functions, methods, classes, and the handful of constructs that make Scala feel like both an OO language and an FP language at once.

Values, Variables, and Functions

  • Values (val) are immutable; variables (var) are mutable
  • Types can be omitted and inferred, or stated explicitly: val x: Int = 1 + 1
  • Anonymous functions are written (x: Int) => x + 1 and can be named by binding them to a val
val add = (x: Int, y: Int) => x + y
println(add(1, 2)) // 3

val getTheAnswer = () => 42
println(getTheAnswer()) // 42

Methods

Methods look and behave like functions but are defined with def, and the return type comes after the parameter list. They can take multiple parameter lists, which is where currying-style APIs come from:

def addThenMultiply(x: Int, y: Int)(multiplier: Int): Int = (x + y) * multiplier
println(addThenMultiply(1, 2)(3)) // 9

The last expression in the body is the method's return value; return exists but is rarely used.

Classes, Case Classes, Objects, and Traits

  • Classes take constructor parameters directly: class Greeter(prefix: String, suffix: String); in Scala 3 no new is needed thanks to universal apply methods
  • Unit is the "nothing meaningful to return" type, like void in Java/C, except every Scala expression must have a value, so Unit has exactly one, written ()
  • Case classes (case class Point(x: Int, y: Int)) are immutable by default and compared by value, unlike ordinary classes which compare by reference, which is what makes them useful for pattern matching
  • Objects are single instances of their own definitions (singletons of their own classes), handy for things like an IdFactory with private state
  • Traits are abstract data types holding fields and methods; a class can extend only one class but multiple traits, with override for replacing implementations
val point = Point(1, 2)
val anotherPoint = Point(1, 2)

if point == anotherPoint then
  println(s"$point and $anotherPoint are the same.")
// ==> Point(1,2) and Point(1,2) are the same.

The entry point is a main method; in Scala 3, simply @main def hello() = println("Hello, Scala developer!").

Notes

Case classes are the construct I expect to reach for most: value equality plus pattern matching is essentially algebraic data types wearing OO clothing, and it maps directly onto the way Elm and Haskell model data with constructors.
