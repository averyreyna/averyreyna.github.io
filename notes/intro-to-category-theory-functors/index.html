Intro to Category Theory: Functors

Category theory is about studying structure-preserving transformations (morphisms). To understand categories, we should understand the structure-preserving morphisms between categories: functors.

Definition

A functor F from category C to category D (F : C → D) maps:

  • objects of C to objects of D, written F c for an object c of C
  • morphisms f : a → b of C to morphisms F f : F a → F b of D

subject to two axioms:

  • (Unit) F ∘ id_x = id_Fx
  • (Composition) for morphisms f : a → b and g : b → c, F(g ∘ f) = (F g) ∘ (F f)

Examples

  • The forgetful functor Grp → Set sends a group to its underlying set and a homomorphism to its underlying function. It forgets the structure but preserves the mapping
  • The free functor Set → Grp goes the other way, sending a set to the free group it generates; the free/forgetful pair forms an adjunction
  • List is a functor on types: it sends a type a to List a, and a function f : a → b to List.map f : List a → List b. The functor axioms are exactly the map laws

Notes

The axioms are the whole point: unit says mapping can't invent or destroy identity, and composition says it doesn't matter whether you compose then map or map then compose. Everything I keep meeting elsewhere is a functor wearing different clothes: monotone maps between semilattices, Galois connections as adjunctions, and map in any functional language.
