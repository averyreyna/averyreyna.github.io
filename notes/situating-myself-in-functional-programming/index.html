Situating Myself in Functional Programming

A holiday-week deep dive into typed functional frontends, working through the Elm guide and the first stops of the Scala tour, plus the opening lecture of the MIT program synthesis course. Elm's architecture and Scala's case classes turn out to be two takes on the same idea: model everything as immutable data and let the types carry the design.
