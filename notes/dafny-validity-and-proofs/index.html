Dafny: Validity and Proofs

Once propositional connectives let me write down a claim, the next question is whether it holds for every assignment of its variables. A truth table settles this mechanically: enumerate every combination of inputs and read the final column. True in every row means the formula is valid; a single false row is enough to sink it.

Truth Tables and Validity

Take (A ∧ B) ⇒ (A ∨ B). An implication is only false when its left side is true and its right side is false, so the only way to break this would be a row where the antecedent holds but the consequent fails — and there isn't one:

A     | B     | A && B | A || B | (A && B) ==> (A || B)
------|-------|--------|--------|----------------------
true  | true  | true   | true   | true
true  | false | false  | true   | true
false | true  | false  | true   | true
false | false | false  | false  | true

Every row in the final column is true, so the formula is valid. Reversing the connectives breaks it. (A ∨ B) ⇒ (A ∧ B) reads "if at least one side holds, then both hold," which is too strong a demand:

A     | B     | A || B | A && B | (A || B) ==> (A && B)
------|-------|--------|--------|----------------------
true  | true  | true   | true   | true
true  | false | true   | false  | false
false | true  | true   | false  | false
false | false | false  | false  | true

The two mixed rows are enough: the antecedent is true while the consequent is false, so the implication is false and the formula is not valid. The same reading explains why A ⇒ (A ∨ B) always holds — or-introduction — and why an implication with a false premise is vacuously true: there is simply no row left for it to fail in.

Substitution and Bound Variables

Substitution is the systematic replacement of every appearance of a symbol with a value or expression, written P[E/x]: every occurrence of x in P becomes E. Whether a variable can be substituted at all depends on whether it is free or bound.

  • A variable is free when nothing in the expression binds it — in f(x) = x + y, y is free because nothing introduces it
  • A variable is bound when a binder, such as a quantifier or a function parameter, introduces it — x is bound by the parameter in f(x) = x + y, and in ∀x. x > z the x is bound by the ∀

The piece a binder reaches over — x > z under the ∀ above — is a subformula of the larger expression. Substitution only touches free occurrences, which is what keeps P[E/x] from quietly capturing a variable that an inner binder already owns.

Arguments and Proofs

A mathematical argument is a set of statements assembled to show that some claim is true or false. A proof is the stricter version: an inferential argument that establishes a given mathematical proposition from its premises by valid steps. The truth tables above are the smallest instance of this — a proof of validity carried out by exhaustion rather than by inference.
