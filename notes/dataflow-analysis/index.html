Dataflow Analysis

Dataflow analysis computes program properties at each point in a control flow graph by propagating information along edges. It is abstract interpretation specialized to control flow graphs.

  • The lattice of abstract values must have finite height for the analysis to terminate, since information can only flow "up" the lattice
  • Classic analyses: reaching definitions, live variables, available expressions, constant propagation
  • The analysis computes a fixed point of a system of dataflow equations, guaranteed to exist by Kleene's fixed-point theorem on a finite lattice
  • Monotone transfer functions at each node update the abstract state; the join operation at merge points combines information from multiple predecessors

The lattice-theoretic fixed point is what CRDT merge and dataflow confluence have in common. Both compute joins toward a least fixed point.
