Abstract Interpretation

Abstract interpretation (Cousot & Cousot, 1977) is a framework for static analysis of programs; it computes sound approximations of program behavior. The key idea: instead of tracking exact values, track abstract values from a domain where computation is decidable. Instead of the exact integer value of a variable, track only its sign (positive, negative, zero).

  • Soundness: if the abstract analysis says a property holds, it holds for all concrete executions, but not vice versa, so false positives are possible
  • The framework is parametric: choose an abstract domain and the analysis follows; the same framework applies to many different properties
  • The abstract domain is a lattice, and the analysis computes a fixed point on it, connecting directly to CRDT convergence

Abstract interpretation is why static analyzers can be sound without being complete. The abstraction trades away precision (false positives) to gain decidability.

The soundness story is made precise by Galois connections between the concrete and abstract domains.
