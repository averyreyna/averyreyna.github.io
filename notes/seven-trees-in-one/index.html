Seven Trees in One

Since T = 1 + T² is a genuine isomorphism, nothing stops you from treating T as an algebraic unknown and solving it like a real equation:

T = 1 + T² ⇒ T² − T + 1 = 0 ⇒ T = 1/2 ± i√3/2

That root is a primitive sixth root of unity, T⁶ = 1. Read as a claim about types, this says there is only one distinct six-tuple of trees, which is obviously false since trees are infinite. Push one step further anyway: T⁷ = T⁶ · T = T. This claim, that seven-tuples of trees are isomorphic to single trees, is not obviously false. It is in fact true (Andreas Blass, "Seven Trees in One"). The route that found it is nonsense the whole way through, since types cannot have fractional, negative, or complex "values." The real proof has to be an honest, explicit bijection built from fold/unfold, no complex numbers involved.

Notes

A legitimate result arrived at by an illegitimate route is not the same as the route being secretly fine. The place where treating a type equation as algebra really is legitimate is generating functions, which count trees rather than solve for T directly.
