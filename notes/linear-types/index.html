Linear Types

Linear types enforce that a value is used exactly once; it cannot be copied or discarded. This models resources: a file handle used twice, or a connection left unclosed, is a type error.

  • Linear logic (Girard, 1987) is the logical foundation; it tracks the number of times a proposition is used as a resource
  • Session types are typically built on linear types: a channel is a linear resource that must be used according to its protocol and then closed
  • Rust's ownership system is an instance of affine types (use at most once), a relaxation of linear types
  • Dafny handles resource-like reasoning through frame conditions and ghost state rather than linear types directly

Linear types make resource management a compile-time concern. The connection to session types: if a channel is linear, you can't accidentally send on a closed connection or handle messages out of order.
