Semilattices

A join-semilattice is a partially ordered set with a join (least upper bound) for every pair of elements; meet is not required.

  • A monotone function between semilattices preserves order: if a ≤ b then f(a) ≤ f(b)
  • CRDT merge functions are join operations on a join-semilattice; this is what guarantees convergence: any order of merges produces the same result
  • The transfer function in dataflow analysis is a monotone function on an abstract domain, connecting lattice theory to abstract interpretation
  • A semilattice homomorphism preserves the join operation, useful for compositional reasoning about distributed systems

The key insight: CRDTs converge because join is idempotent (a ∨ a = a), commutative (a ∨ b = b ∨ a), and associative. These three properties, not any protocol, are what guarantee consistency.
