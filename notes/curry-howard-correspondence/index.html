Curry–Howard Correspondence

The Curry–Howard correspondence identifies propositions with types and proofs with programs: a type A is a proposition, a term of type A is a proof that A holds, so type-checking a program is the same as proof-checking a theorem.

  • The extended Curry–Howard–Lambek correspondence adds a third leg, categories: propositions = types = objects; proofs = programs = morphisms; logical connectives = type constructors = categorical constructions
  • Dafny uses this implicitly: its verification conditions are proof obligations, and the verifier checks them automatically via Z3
  • Category theory is the semantic model that explains why the correspondence works

This is the bridge between Dafny (proofs as verification) and category theory (categories as semantics). Agda makes it explicit: every type is a proposition you can prove by writing a term.
