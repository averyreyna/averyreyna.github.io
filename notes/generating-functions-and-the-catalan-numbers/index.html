Generating Functions and the Catalan Numbers

Solving T = 1 + T² directly for T is nonsense, but there is a place nearby where treating the equation as algebra is completely legitimate: counting.

Counting Trees by Size

Count trees by size, meaning the number of Nodes. A size-n node splits into independently-chosen left and right subtrees whose sizes sum to n − 1, so the counts obey a convolution, which is exactly what multiplying power series does. Package the counts into T(x) = Σ aₙ xⁿ and the recursive structure becomes a legitimate quadratic in the bookkeeping variable x (which tracks size, not "the value of the type"):

T(x) = 1 + x · T(x)²

Solving this reproduces the Catalan numbers, 1, 1, 2, 5, 14, 42, …, real, meaningful, non-negative integer counts. This explains why something interesting was lurking in the tree equation, but it is not the same move as solving T = 1 + T² for T itself; that stays invalid.

Contrast: the Naturals

The naturals, t = 1 + t (Z | S of t), have no branching, no product, in their recursive case. Solving algebraically gives t − t = 1, i.e. 0 = 1, a flat contradiction, which reflects that there is no fixed point: you can always build a bigger t. The generating function is B(x) = 1/(1−x), the trivial geometric series, with no interesting roots, because there was never a combinatorial choice being made.

Notes

The tree equation was interesting precisely because T × T encodes a real choice, namely which subtree gets which size, and that same 2 from the product shows up again as a genuine data field in the tree zipper.
