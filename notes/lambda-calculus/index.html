Lambda Calculus

The lambda calculus is a formal system for expressing computation via function abstraction and application: λx. e is a function taking x and returning e, and (λx. e) v reduces to e[v/x], substituting v for x in e (β-reduction).

  • The simply typed lambda calculus (STLC) assigns types to terms to rule out nontermination; types are built from base types and the function type A → B
  • Every well-typed STLC term terminates (strong normalization)
  • Under Curry–Howard, A → B is implication: a function from A to B is a proof that A implies B
  • PLFA (Programming Language Foundations in Agda) covers the lambda calculus formally and mechanizes the metatheorems in Agda

Lambda calculus is the computational core of type theory and the semantic foundation for functional languages like Elm. Agda is essentially a dependently-typed lambda calculus with a universe hierarchy.
