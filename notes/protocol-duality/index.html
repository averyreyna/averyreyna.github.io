Protocol Duality

Duality in session types: if one side sends, the other receives, so the type of one end of a channel is the dual of the other.

  • dual(!A.S) = ?A.(dual S), dual(?A.S) = !A.(dual S), dual(end) = end
  • Duality ensures a well-typed system of two communicating processes cannot deadlock on a single channel; the types guarantee compatible behavior
  • This is a form of the Curry–Howard correspondence extended to communication: session types correspond to linear logic propositions, and duality corresponds to negation
  • Duality in session types is related to categorical duality (reversing all arrows), and the correspondence has been formalized using proof nets

Duality is what makes session types compositional. If both ends of every channel are typed with dual types, the system as a whole is guaranteed to be deadlock-free.
