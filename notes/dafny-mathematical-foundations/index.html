Dafny: Mathematical Foundations

Before the verifier can prove anything, the specifications need a vocabulary, and that vocabulary is naive set theory. These are notes on the mathematical objects Dafny's specification language is built from.

  • Finite sets can be denoted by roster notation, listing the elements: {1, 2, 3}
  • An n-tuple is an ordered collection of n objects, denoted by commas separating the list of objects within parentheses
  • Roster notation is inconvenient for large sets and impossible for infinite sets, hence set-builder notation, which describes a set by the property its members satisfy: {x | x > 0}

Notes

Set-builder notation is the bridge to verification: a Dafny postcondition like ensures GreaterThanZero(x) is really carving out the set of values the program is allowed to produce. The predicate is the set. See Dafny: Logic for how quantifiers turn these descriptions into provable claims.
