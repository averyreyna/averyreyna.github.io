Dependent Types

A dependent type is a type that can depend on a value. The type of "a vector of length n" is dependent: the type changes based on the value n.

  • Π-types (dependent functions), written Π(x : A). B(x): given a : A, produce a term of type B(a), generalizing function types
  • Σ-types (dependent pairs): a pair (a, b) where b has type B(a), generalizing product types
  • Agda is built on dependent type theory; all proofs in PLFA are Agda terms with dependent types
  • Dafny uses a restricted form: specifications are a kind of dependent type, but without the full generality of Agda

Σ-types are propositions with witnesses: "there exists x such that P(x)" is Σ(x : A). P(x). The pair is the x and the proof that P holds.
