Session Types

Session types are a type discipline for communication protocols. The type of a channel describes the sequence of messages that will be exchanged on it. A session type enforces that both sides of a communication follow the protocol at the type level: protocol violations become type errors.

  • Basic constructs: !A.S (send a value of type A, continue with session S), ?A.S (receive A, continue with S), end (session complete)
  • Introduced by Honda (1993) and developed by Caires, Pfenning, Wadler, and others
  • Work by Caires and Pérez connects session types to CRDTs, giving typed guarantees about distributed protocols carrying replicated state

Session types are to communication what type theory is to computation: a way of ruling out entire classes of errors at compile time, before the program runs.
