Daydream

Daydream is a SvelteKit playground that turns pasted code into Mermaid diagrams via Claude. An edit mode lets you drop draggable text annotations and freehand highlight strokes directly on top of the result, with pointer input decimated by distance so slow drags don't produce thousands of redundant points.

Envisiage

Envisiage is an inline code tutor built on a multi-file Monaco editor: select any span of code, press a shortcut, and an AI explanation streams into a panel anchored to that selection. A small "granularity" layer (ELI5, step-through, technical, debug) steers the same underlying prompt toward a different kind of answer depending on what you need.

Catalyst

Catalyst is a desktop editor, built with PyQt6, for turning photos into pointillist mosaics. You load an image, tune block size and color settings, and export a PNG or a print-ready PDF with grid overlays and ruler ticks sized for an actual painting layout. The mosaic itself comes from a fully vectorized block-averaging pass over the image in NumPy, with no per-pixel loops even when spacing blocks apart with gaps.

Convoy

This was the first version of Convoy, before it grew into a Python/notebook codegen tool: a canvas-based node graph for building data pipelines, where dragging in sources, filters, and transforms produces a chart you can push straight to Datawrapper instead of a static export. The pipeline ran entirely as an in-memory DataFrame, translated into a Datawrapper-compatible chart type and CSV payload on export.

Chaperone

Chaperone is an editor for a pandas-like method-chain DSL that gives you live, data-derived feedback as you type, built in the style of Hazel's hole-driven editors. Write a short pipeline against a real CSV and Chaperone infers a rich column schema straight from the data, then hands you squiggles, a ranked completion inspector, and a live result pane before anything actually runs. Swapping the underlying CSV re-runs everything and names exactly which step's assumptions broke.

Conjure Code

Conjure Code is a CLI that turns a codebase (local, or a GitHub slug like sveltejs/kit) into a navigable node graph, using ts-morph to statically analyze exports, functions, classes, and their references, then serving the result as an interactive canvas with files and modules as nodes and imports and calls as edges. Viewport culling on every pan and zoom keeps even much-larger-than-screen graphs smooth.

CoupView

CoupView is a proof-of-concept map for exploring historical coups and illegal leader turnover around the world, rendered as a GeoJSON feature collection on a dark-themed MapLibre GL basemap. Each event is color-coded by outcome directly in the map's GL style, with a sidebar for searching and filtering by region, decade, outcome, and tag, and a popup for drilling into a single case.

Transparent

Transparent takes a plain-language UI request, generates working HTML/CSS/JS for it with Claude, renders the result live, and then explains its own output back to you: concept by concept, tied to specific line numbers, ordered from beginner to advanced. The idea is to make generated code legible rather than a black box you just paste and run.

Form

Form is a notes app with an unusual second half: alongside the notes overview and editor sits a feature builder where you write a small React/TypeScript component and have it become a live part of the running app, no rebuild or redeploy required. The sandbox compiles and runs the code entirely in the browser, and a broken feature fails as a small error box in place rather than crashing the rest of the app.

Palestra

Palestra is a coding education workspace (file explorer, code editor, and chat panel in one) where the codebase you're practicing on doesn't have to exist yet: Claude generates an entire project from a short description, and the result becomes something you can click through and edit like a real repo. As far as the UI is concerned, an AI-generated codebase and a hand-written one look identical.

Rerank

Rerank runs the same document through three summarization methods (TextRank, LexRank, and BART) and lets you compare their output side by side instead of committing to whichever one a library defaults to. TextRank and LexRank are implemented directly in TypeScript and run entirely client-side, scoring sentences by how similar they are to every other sentence in the document.

Perceptor

Perceptor is a CLI coding tutor built around a Socratic method system prompt: it's told outright to never hand over a direct answer, and instead break whatever a student is stuck on into a small, immediately doable exercise. A student can ask about "codebase structure" mid-conversation in plain language, which triggers a static analysis of the current directory to get appended to the message before it reaches Claude.

Scrutinize

Scrutinize is a document viewer for close-reading and annotating essays. Text is generated on demand by DeepSeek's chat model from whatever topic you type in, so you get a fresh document to mark up every time; you select a phrase, tag it with an annotation type and a short note, and the tool tracks that span as a highlighted region going forward.

Specter

Specter is a writing assistant built around a deliberate constraint: the system prompt tells DeepSeek its goal is "not to write the text for the user, but to help the user write better." Instead of generating replacement prose, every analysis pass returns potential directions to develop and specific areas for improvement, keeping suggestions as scaffolding around your draft rather than content that could replace it.

Meta Measure

Meta Measure takes a list of research ideas and places them on a scatter plot, quantitative to qualitative on one axis and traditional to novel on the other, with every placement reasoned fresh by Claude rather than a fixed rubric. Every response also has to interrogate its own placements: what it assumed, what it defaulted to, and whether its evaluation favors certain approaches over others.

Built with agentic tooling like GitHub Copilot, partly to walk the talk. The playground itself has data tables with inline editing, a JSON view toggle, and batch operations.

Admin Metrics Dashboard

An in-house admin dashboard for cyber log monitoring, built to replace a Grafana-heavy setup with views actually tuned to how our operators triage things day to day, in React, TypeScript, and Python. The main additions were timeframe filtering, threshold-based alerting, and inventory tracking across more than 5,000 assets.
