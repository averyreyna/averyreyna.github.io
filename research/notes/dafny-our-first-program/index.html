Dafny: Our First Program

Dafny incorporates at least two formal systems: mathematical logic at compile time, and evaluation of programs at runtime. If a program compiles successfully, meaning Dafny manages to prove whatever we ask of it, it proceeds to execute at runtime. Verification of proofs first, then compiled code.

method Main()
    ensures 3 * 2 == 6
{
    print "Hello World!\n";
}

The area before the body is the specifications area; if a specification is not met, we get an error at compile time. Change the claim to something false and the verifier objects:

method Main()
    // this will cause an error saying "a postcondition might not hold
    // in this return path"
    ensures 3 * 2 == 7
{
    print "Hello World!\n";
}

Notes

What makes this a good first program: the ensures clause has nothing to do with the body. The program prints a greeting; the proof obligation is pure arithmetic. Keeping those two layers visibly separate from the very first example is the clearest statement of what Dafny is.
