Admin Metrics Dashboard

May 25, 2025

An in-house admin dashboard for cyber log monitoring, built to replace a Grafana-heavy setup with views actually tuned to how our operators triage things day to day. It was the first iteration of a custom monitoring system in React, TypeScript, and Python. The main additions were timeframe filtering, threshold-based alerting, and inventory tracking across more than 5,000 assets, so admins could catch anomalies instead of scrolling through pages of widgets that didn't let them customize much of anything.
