Admin Metrics Dashboard

May 2025

An in-house admin dashboard for cyber log monitoring, designed to replace a Grafana-heavy setup with views tuned to our operators' workflows, alert semantics, and day-to-day triage habits. This was the first iteration of a custom monitoring system built in React, TypeScript, and Python. We added dynamic timeframe filtering, real-time threshold alerting, and granular inventory tracking across >5k assets, so admins could actually catch anomalies instead of scrolling through pages of widgets that lack customizability.
