CoupCats

May 11, 2026

CoupCats is a web application for visualizing and predicting political coup risk worldwide. The starting point for all of it is a dataset of country-level coup probabilities—yhat values from R models trained on historical event data—loaded into the frontend as a static JSON file that gets swapped in whenever new predictions are available. That data drives a choropleth map where color encodes risk tier, a leaderboard of the highest-risk countries at any given moment, and individual country panels that surface the underlying numbers alongside narrative context written for each case.

The map layers two things on top of each other: the baseline model forecast and a heatmap of historical coup events pulled from a separate events dataset. Seeing them together matters—a country with high predicted risk but no event history looks different from one with both), and the two signals rarely tell the same story. Clicking into a country opens a panel with event-by-event detail, including date, type, and outcome.

Beyond the baseline forecast, a predictive mode lets you move sliders tied to individual risk factors and watch the map update in response. The sliders don't retrain anything, but the effect is that you can interrogate the model's sensitivity to each variable and ask what the risk landscape looks like if conditions change.

The frontend is React and TypeScript, with MapLibre for the map layer, Turf.js for country geometry operations, and Zustand managing the filter and selection state shared across the map, panels, and leaderboard. The R models that produce the underlying forecast data run entirely separately; the app is a consumer of their output, not a host for the computation.
