Metrics Playground

December 20, 2025

A hands-on playground for metrics and evaluation workflows, built for Cyber D&M engineers, and really about how agentic software development changes instrumentation, feedback loops, and what we even choose to measure. I built the whole thing with agentic tooling like GitHub Copilot, partly to walk the talk: these tools make low-stakes experimentation a lot easier, and spinning up an interactive prototype stopped requiring much overhead at all. The playground itself has data tables with inline editing, a JSON view toggle, and batch operations, so engineers get a real sandbox to poke at metadata instead of jumping between tools.
