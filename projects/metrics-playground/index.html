Metrics Playground

December 2025

A hands-on playground for metrics and evaluation workflows aimed at Cyber D&M engineers, focused on how agentic software development changes instrumentation, feedback loops, and what we choose to measure. I built the whole thing using agentic tooling like GitHub Copilot to walk the talk, showing how these tools invite low-stakes experimentation and make it way easier to spin up interactive prototypes without a ton of overhead. The playground itself includes interactive data tables with inline editing, JSON view toggles, and batch operations, giving engineers a real sandbox to explore and validate metadata without jumping between tools.
