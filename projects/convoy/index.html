Convoy is a canvas-based data pipeline builder. You drag nodes onto a React Flow canvas (sources, filters, group-bys, sorts, transforms, computed columns, reshapes, and chart outputs), wire them together, and the pipeline runs, with a data preview on each node so you can inspect what a step produces without leaving the canvas. A code panel alongside generates equivalent Python (or a Jupyter notebook) at every change, staying in sync automatically, and you can export either or paste Python back in to reconstruct the graph. Chart previews render through a short-lived Python/matplotlib subprocess rather than anything in the browser, and an AI layer powered by the Anthropic API can suggest nodes, explain one, edit its configuration from plain language, or diagnose an error state.
