Specter

May 11, 2026

Specter is a writing assistant powered by DeepSeek. You write in a textarea, optionally give the editor a topic, and ask for two things: an analysis of what you've written, or inspiration for how to start. Nothing you write is saved between sessions.

The analysis path sends your text — prepended with the topic if you supplied one — to deepseek-chat with a system prompt that instructs the model to return two labeled sections: potential directions for development and specific areas for improvement. The frontend splits the response on the "Areas for Improvement" heading, strips the heading lines, and distributes the bullet points into two side panels. Blue dots for directions, red for improvements. If the model returns an empty section the panel just stays blank.

The inspiration path works differently. A modal prompts you to describe what you need help starting — a topic, a challenge, a genre — and the model returns a short list of opening hooks and a rough outline. Instead of replacing your draft, the response is appended to the textarea. The idea is that you keep writing; the model hands you raw material rather than a finished thing.

Both calls go through the same DeepSeekClient class wrapping axios, but the component uses two separate useDeepSeek hook instances so the analysis and inspiration loading states don't interfere with each other. If you click Inspiration while an analysis is still running, neither request is blocked.
